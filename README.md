# Teclado Flechinha

Teclado Android com modo "Ponteiro": arraste o dedo pra mover o cursor, selecione, copie, recorte e cole em qualquer app.

Como usar: instale o APK, abra o app, toque em "1. Ativar o teclado" e depois em "2. Escolher como teclado atual".

Compilar: envie esta pasta para um repositório no GitHub (branch main). Em Actions, "Build APK" gera o arquivo TecladoFlechinha-apk (app-debug.apk).
